Nebula

A Material You desktop shell for Hyprland, built with Quickshell. Your wallpaper sets the colours for the bar, dock, widgets, dashboard and lock screen, and for your other apps if you want.

$ bash <(curl -fsSL https://raw.githubusercontent.com/iamSt3el/Nebula/master/install.sh)
Arch Linux warningHyprland 0.56+ with a Lua config GPL v3 Watch the tour
warning Hyprland 0.56+, configured in Lua

Your config must be ~/.config/hypr/hyprland.lua. The classic hyprland.conf is not supported: Nebula sends Hyprland its window and workspace commands in Lua, and a .conf setup rejects them.

terminal Arch Linux

The installer uses pacman and an AUR helper, and installs yay if you have neither.

check Everything else is installed for you

Quickshell, fonts, Python and the native plugins. nebula doctor checks what is missing.

Under the hood

Where the colours and numbers come from.

paletteMaterial You colours

A palette from your wallpaper, cached per image. Terminal colours stay readable in light and dark mode, and GTK, Qt, Firefox and Obsidian follow along.

terminalOne command

Everything the shell runs in the background goes through nebula, so you can drive it from a terminal or a keybind too.

memoryNative plugin

System stats, sparklines and the Material shape painter run in C++ instead of QML, to keep the shell light.

cloudWeather and holidays

Weather from Open-Meteo and public holidays for your country, both worked out from your timezone until you set a town. No accounts.

Layouts

Save your desk, switch it in one click

A layout is a snapshot of how the shell is arranged. Keep one for work and one for gaming, try something new without losing what you had, and share yours as a plain JSON file.

toolbarBar and dock widgetsDesktop widgets space_dashboardDashboard searchPanel styles lockLock screen paletteWallpaper and colours

Loading a layout keeps your current one so you can undo. Your notes, habits and other data are never part of a layout.

nebula layout save "Work"
nebula layout load gaming
nebula layout undo
nebula layout import ~/Downloads/cozy.json
Setup

One window to set it up

Run nebula setup. It opens in the middle of the screen, walks you through six steps and closes completely when you're done.

  1. 1WallpaperBrowse your folder; the colours follow straight away.
  2. 2ColoursLight or dark, and how bold the palette is.
  3. 3AppsNebula finds what's installed. Switch on the apps that should follow the palette.
  4. 4You, shortcuts, finishYour picture, font and weather, the shortcuts to bind, then a check of every app it themed.

Command line

Drive it from a terminal

The same command the shell uses in the background. nebula help lists everything else, like weather, storage and layouts.

nebula start                        # or stop, restart
nebula setup
nebula wallpaper set ~/wallpaper/forest.png
nebula wallpaper random
nebula scheme set --mode light          # or --variant vibrant
nebula apps disable gtk3 gtk4 --apply
nebula layout save "Minimal"             # and load, undo, import
nebula doctor                           # anything missing?
nebula ipc widgets edit                 # call the running shell
Install

Three steps on Arch

The installer pulls the packages, builds the plugins, sets up Python and fonts, and installs the nebula command to /usr/local/bin. It also puts Nebula's shortcuts, layer rules and autostart in ~/.config/hypr/nebula/ and loads them from your hyprland.lua, after a backup.

1Run the installer

bash <(curl -fsSL https://raw.githubusercontent.com/iamSt3el/Nebula/master/install.sh)

Add -f to skip the questions, -s to skip the system update.

2Log in again

require("nebula.autostart")

The installer adds this to hyprland.lua, so Nebula and the clipboard watcher start with Hyprland. Parts your config already has stay commented out.

warningLua config only. There is no hyprland.conf version of this step, because Nebula does not work with a .conf setup.

3Set it up

nebula setup

Pick a wallpaper, your colours and which apps follow them.

Shortcuts, ready to change

Nebula's global shortcuts are named quickshell:<name>. The installer binds them in ~/.config/hypr/nebula/keybinds.lua; change the keys there and updates leave the file alone.

hl.bind("SUPER + CTRL + RETURN", hl.dsp.global("quickshell:appLauncher"))
hl.bind("SUPER + L", hl.dsp.global("quickshell:lock"), { locked = true })
