Your wallpaper picks the colours. You arrange the rest.

Nebula is a desktop shell for Hyprland, built with Quickshell. It gives you a bar on any edge of the screen, desktop widgets, a launcher, a dashboard and a lock screen, all coloured from your wallpaper with Material You.

Install on Arch Linux
bash <(curl -fsSL https://raw.githubusercontent.com/iamSt3el/Nebula/master/install.sh)
Arch Linux Hyprland 0.56+ with a Lua config GPL-3.0

One bar, four shapes

Blocks on an edge can float as pills, fuse into one piece, step down from the screen edge or join into a full strip. Three numbers make the difference: how far the bar sits from the edge, the gap between blocks, and how much of the space between groups gets filled. Try them on the bar at the top of this page.

Panels open the way you like

Each bar item opens its own panel: weather, sound, Wi-Fi, Bluetooth, battery, music, the calendar and more. Pick how a panel meets the bar.

Set a style once for a whole edge, then give any single block its own. When blocks are merged or the bar is a full strip, a panel treats the joined blocks as one piece.

Rearrange it in place

Edit mode opens over your real desktop. Nothing is a mock-up: you move the actual bar and see each change as you make it.

  • Any item, any edgeDrag items and whole blocks between the top, bottom, left and right edges.
  • Per-block controlsRight-click a block to set its gaps, lift it off the edge or round its corners.
  • An edge at a timeEach edge has a drawer for its shape, size, gaps and how its panels open.
  • Undo with historyEvery change is one undo step, and the whole history is a click away.
  • Saved layoutsKeep whole setups, with bar, widgets, panels and wallpaper, and switch between them in one click.

Run it from a terminal

The shell does its background work through one command, and you can use it too.

nebula start              # or stop, restart
nebula setup              # wallpaper, colours, apps
nebula wallpaper set ~/wallpaper/forest.png
nebula scheme set --mode light
nebula layout load evening
nebula doctor             # anything missing?

Install it

Nebula runs on Arch Linux. The installer sets up everything it needs and backs up what it replaces.

  1. Run the installer

    It installs the packages, builds the plugins, installs the nebula command and copies Nebula's Hyprland config into ~/.config/hypr, offering a backup first.

    bash <(curl -fsSL https://raw.githubusercontent.com/iamSt3el/Nebula/master/install.sh)

  2. Log in again

    Hyprland starts Nebula from its new config. The installer also sets up kitty, the Starship prompt and the Nebula login screen.

  3. Run nebula setup

    Pick a wallpaper, your colours and which apps follow them. You can change all of it later in Settings.

Nebula needs Hyprland 0.56 or newer with a Lua config (~/.config/hypr/hyprland.lua). The classic hyprland.conf format is not supported, because the shell sends Hyprland its commands in Lua. The installer's hyprland.lua is built from Hyprland's own defaults, so you start from a working config.
