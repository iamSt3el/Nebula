Widget canvas

A full-screen canvas that you lay out by hand. Widgets are dragged into place and keep their position; everything is themed from the current palette.

Opening the canvas

The widget screen is on the quickshell:toolsWidget shortcut. Bind it as described in Keybindings.

Available widgets

GroupWidgets
TimeAnalog clocks (classic, minimal, shaped), digital clock, date cards in several styles, calendar
WeatherForecast card, sun arc, moon phase
SystemCPU and memory monitors, network graph, battery (bar, minimal and ring forms), temperature
MediaMedia player controls, album art, CAVA audio spectrum
NotesSticky notes, task list, pomodoro timer
FeedsRSS headlines
ProfileProfile card and tile

Arranging them

Widgets are placed by dragging. Which widgets are enabled, and their layout, is part of the settings stored in ~/.config/nebula/settings.json — see Settings.

Widgets follow the wallpaper

Every widget takes its colours from the generated palette rather than carrying its own, so changing the wallpaper restyles the whole canvas. See Theming other apps.

Weather and feeds need network access

The weather, RSS and holiday widgets fetch over the network using the Python environment. If they stay empty, confirm NEBULA_VENV is exported and that requests is installed in it — Dependencies has the commands.
